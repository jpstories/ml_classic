# LightGBM: Работает в разы быстрее CatBoost и Random Forest. Отлично справляется с огромными датасетами и экономит оперативную память. Использует рост дерева «вглубь» (leaf-wise).
# XGBoost: Золотой стандарт соревнований Kaggle. Обладает огромным количеством регуляризаторов, что помогает бороться с переобучением, если данных не очень много.

# Deep Learning
- FT-Transformer (Feature Tokenizer + Transformer): Адаптация архитектуры трансформеров для таблиц. Превращает каждый признак в эмбеддинг. Долго обучается, но часто побеждает бустинги на сложных данных.
- TabNet: Нейросеть от Google, использующая механизм последовательного внимания (attention) для выбора наиболее важных признаков на каждом шаге.
