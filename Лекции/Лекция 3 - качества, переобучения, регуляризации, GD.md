## 1. Оценка обобщающей способности модели

- **Кросс-валидация (K-Fold):** Разбиение обучающей выборки на $K$ блоков. Модель обучается $K$ раз на всех блоках, кроме одного, который выступает в качестве тестового. Это позволяет получить более объективную оценку качества и защититься от неудачного распределения выбросов
    
- **Итоговая модель:** После кросс-валидации финальную модель можно получить двумя путями — либо заново обучить на всех доступных данных, либо усреднить прогнозы $K$ полученных моделей
    
- **Выбор количества блоков:** Чем меньше у вас данных, тем больше должно быть $K$ (вплоть до Leave-One-Out, когда размер блока равен одному объекту)
    

## 2. Борьба с переобучением: Регуляризация

- **Симптомы переобучения:** Если линейная модель переобучилась (запомнила шум в данных), её веса становятся аномально большими. Решение — «штрафовать» модель за большие веса 
    
- **L2-регуляризация (Ridge):** Добавление к функции потерь (например, MSE) штрафа в виде квадрата L2-нормы вектора весов, умноженного на коэффициент $\lambda$. Это делает матрицу невырожденной и гарантирует аналитическое решение 
    
- **Правило свободного коэффициента:** Свободный коэффициент ($w_0$) **нельзя** включать в регуляризатор, иначе модель не сможет подстроиться под масштаб целевой переменной 
    
- **Подбор гиперпараметра $\lambda$:** Гиперпараметры нельзя подбирать по обучающей выборке (иначе оптимальным будет $\lambda = 0$). Их подбирают исключительно по отложенной выборке или через кросс-валидацию 
    
- **Линейно зависимые признаки:** Регуляризация элегантно решает проблему мультиколлинеарности (когда решений бесконечно много из-за линейной зависимости признаков), выбирая из всех возможных решений то, у которого веса минимальны 
    

## 3. Градиентный спуск

- **Ограничения аналитического решения:** Обращение матриц — слишком вычислительно затратная операция при большом числе признаков (сложность $O(d^3)$), поэтому на практике используют численные методы
    
- **Интуиция градиентного спуска:** Итеративное движение в сторону антиградиента (направления наискорейшего убывания функции). Для выпуклых функций линейной регрессии этот метод гарантированно находит глобальный минимум
    
- **Условия остановки:** Спуск останавливают, когда ошибка на тестовой выборке перестает уменьшаться, либо когда изменения весов становятся пренебрежимо малыми
    
- **Стохастический градиентный спуск (SGD):** Вместо вычисления градиента по всей огромной выборке (что долго), градиент оценивается всего по одному случайному объекту. Шаги становятся «шумными», но вычисляются мгновенно 
    
- **Mini-batch:** Компромиссный вариант, при котором градиент оценивается по небольшой подвыборке (например, по 100 объектам). Это позволяет эффективно использовать память и реализовывать потоковое обучение (чтение данных с диска по частям) 
    
- **Метод SAG (Stochastic Average Gradient):** Интересный теоретический метод, в котором хранятся градиенты для всех объектов, а на каждом шаге обновляется только один из них
